# OLA Ride Booking Data Analysis

## 📌 Project Overview
This project focuses on analyzing OLA ride booking data using PostgreSQL and developing an interactive Power BI dashboard to identify booking trends, ride patterns, cancellations, and customer and driver ratings.

## 🛠️ Tools & Technologies
- PostgreSQL – Data querying and analysis
- pgAdmin 4 – Database management
- Microsoft Power BI – Dashboard development and visualization
- SQL – Data filtering, aggregation, grouping, and analysis

## 🔍 Key Analysis Areas
- Successful and canceled booking analysis
- Average ride distance by vehicle type
- Customer and driver rating analysis
- Customer and driver cancellation patterns
- Booking performance and key metrics
